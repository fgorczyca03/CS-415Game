##CS415 Horror Game

*📌 *Project Overview

This is a horror game developed in Unity as part of the CS415 class during the summer of 2024. The game is set in a dark, abandoned church where players must complete various tasks to survive. The eerie atmosphere and sound design enhance the sense of fear and tension.

Course: CS415 - Computer Game Development

Semester: Summer 2024

Development Team: Filip Gorczyca, Nathaniel Cunningham, Karissa Wiggins, Julie Loughlin

Development Duration: 3 weeks

Development Method: Agile (iterative sprints)

🎮 *Gameplay

The player is trapped in a haunted church.

To escape, they must complete a series of tasks.

The game includes:

Time-sensitive challenges

A dynamic horror atmosphere (sound effects, lighting, and environment design)

🚀 *Features

Dark, atmospheric church environment.

Interactive objects that the player can inspect or use.

A series of tasks and puzzles that must be completed to survive.

Dynamic sound design to enhance the horror experience.

🛠️ *Development Details

Game Engine: Unity

Programming Language: C# (for game logic)

Development Method: Agile, with 3 sprints of 1 week each.

Tools Used:

Unity Editor

Visual Studio (C# coding)

GitHub for version control

Trello

⚡ *How to Run the Game

Clone this repository:

git clone https://github.com/fgorczyca03/CS-415Game.git

Open the project in Unity

Build and run the game using Unity’s Build Settings (Windows, macOS, or WebGL).
